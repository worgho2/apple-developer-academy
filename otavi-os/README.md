# otavi-os

otaviOS is an iOS app that recreates the look, sound and feel of a Windows XP era desktop, built for the first Nano Challenge at the Apple Developer Academy as a full rewrite of the earlier `windows-98-crash` project.

The UIKit app boots through a startup screen into a desktop with working windows for a console, Internet Explorer, Notepad, alerts, a shutdown sequence and a "crack" screen. Custom Audio and Haptic Feedback modules play the classic system sounds and give mechanical typing feedback, with fonts and 11 sound tracks bundled. `docs/` holds the challenge deliverables: the demo video (`demo.mp4`) and the Keynote presentation (`keynote.key`).

## Run

Open `otaviOS.xcodeproj` in Xcode and run. Swift 5, iOS 13.2 or later.
