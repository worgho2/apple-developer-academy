# oraculo

SwiftUI iOS app built for the second Nano Challenge at the Apple Developer Academy. It helps educators keep track of students: who is in which class, their grades per term, and behavioural occurrences assigned by educators.

`DataProvider` serves mock data to the views. `StudentView`, `EducatorView` and `SearchStudentView` browse and search people, `AssignOccurrenceView` records an occurrence for a student, `PrintTermView` exports a term report as PDF, and `SettingsView` exposes admin features and access levels (admin, editor, user). The challenge deliverables (presentation, demo video and reflection) are excluded by the project's `.gitignore`.

## Run

Open `oraculo.xcodeproj` in Xcode and run. Swift 5, iOS 13.2 or later.
