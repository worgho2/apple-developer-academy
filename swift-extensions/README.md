# swift-extensions

Collection of small Swift extensions collected at the Apple Developer Academy for UIKit and SpriteKit work. There is no package manifest; copy the files you need into a project.

- `CGPointExtensions`, `CGSizeExtensions`, `CGVectorExtensions`: vector arithmetic and distance helpers.
- `SKSceneExtensions`, `SKNodeExtensions`, `SKSpriteNodeExtensions`: coordinate conversion and positioning helpers for SpriteKit scenes.
- `UIViewExtensions`: tap gesture handling through a closure property.
- `UILabelExtension`: text styling helpers.
